# Maasai Market Online Frontend

This repository contains the frontend code for the Maasai Market project, an e-commerce platform dedicated to showcasing and selling authentic Maasai and African antiques, jewelry, and fabrics. The frontend is built with VueJS to provide a dynamic and responsive user interface.

## Table of Contents

1. Introduction

2. Features

3. Installation

4. Usage

5. License

## Introduction

The frontend is designed to provide a seamless shopping experience for users. It includes components for browsing products, viewing product details, and managing pre-orders.

## Features

- Dynamic Product Display: Showcase authentic Maasai and African products with interactive components.
- Responsive Design: Ensure a smooth experience across various devices and screen sizes.
- User-Friendly Navigation: Easy-to-navigate interface for a better user experience.
- Integration with Backend: Connects with the Cargosai backend for data retrieval and interaction.

### Prerequisites

- Node.js: Ensure you have Node.js and npm installed. You can download them from nodejs.org.

### Setup

1. Clone the Repository

```
git clone https://github.com/yourusername/cargosai.git
cd cargosai
```

2. Install dependencies:

```
npm install
```

3. Run the Development Server

```
npm run dev
```

The application will be available at http://localhost:3000 by default.

#### Usage

Once the development server is running, you can view and interact with the frontend in your web browser. The application allows you to:

- Browse product categories
- View detailed product information
- Place pre-orders for products
